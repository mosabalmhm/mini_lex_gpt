# MiniLexGPT

MiniLexGPT is a small decoder-only English language model built from 
scratch with PYthon and PyTorch.


## Project goals

- Train a custom Byte-Level BPE (Byte-Pair Encoding) tokenizer.
- Build a modern decoder-only Transformer architecture.
- Pretrain on open English lexical and textual data.
- Fine-tune on short conversational data.
- Run training and inference on limited CPU hardware.
- Document every architectural and mathematical component.
 
## Planned architecture

- RMSNorm.
- Causal Multi-Head Self-Attention.
- SwiGLU Feed-Fordward Network 
- Residual Connections
- Weight Tying
- Next-token Prediction.
